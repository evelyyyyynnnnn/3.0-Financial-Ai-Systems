What this does not establish

  • 19 of 22 projects compute their result on real public data, each with a data manifest (source URLs, sha256 hashes, retrieval times). The remaining 3 use synthetic-by-design or authored data and are labelled as such.
  • Several projects were validated against corpora written by the same person who wrote the method. Those figures measure internal consistency, and each project's own page says so.
  • 0 projects have no recorded run at all.
  • This page checks that figures trace to a run. It cannot check that the run was well designed — that judgement stays with each project's page.
