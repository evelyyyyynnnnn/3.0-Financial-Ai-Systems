Financial Stability

Live Trading Engine

实盘交易执行引擎（C++ / Python 双实现） — Low-latency factor trading against the Alpaca API, in C++ and Python.

做什么

The execution layer. A C++17 engine built for microsecond-level decisions — multi-threaded, WebSocket market data, order management, risk limits, performance monitoring — mirrored by a Python implementation carrying a library of factor strategies.

C++17CMakeBoostWebSocket++PythonAlpaca API

Platform. C++ 引擎 README 注明仅在 macOS 14.6 上测试过。

核心模块

路径相对于 project-1/live-trading-engine/。

模块职责
