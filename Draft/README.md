# Draft

Prototype and research projects for the financial AI systems work. Eight projects
live here; four of them ship browser-facing pages.

**[`website/index.html`](website/index.html) is the visual index** — open it in a
browser and every page below is one click away. GitHub will not render it inline,
so the same inventory is written out here.

---

## Website pages

Twelve pages, grouped by what it takes to open one.

### Live dashboards

Application front-ends. Each fetches from its own backend, so start the server
first; opening the file directly renders the shell without data.

| Page | What it covers | Run it |
|---|---|---|
| [智能投资分析专家仪表板](trading-system-dashboard/index.html) | Investment analysis driven by live market data and AI commentary | `cd trading-system-dashboard && npm install && npm start` → <http://localhost:3000> |
| [Trading Simulation Platform](trading-system-dashboard-2/public/index.html) | Quantitative trading dashboard with a backtesting engine and Socket.IO live updates | `cd trading-system-dashboard-2 && npm install && npm start` → <http://localhost:3000> |
| [MarketWatcher — Options Volatility Monitor](volatility-forecasting/Options-Volatility-Trading/webapp/templates/dashboard.html) | Straddle opportunities across a watchlist. A Jinja template — Flask must render it | `cd volatility-forecasting/Options-Volatility-Trading && pip install -r webapp/requirements.txt && python webapp/app.py` → <http://localhost:8080> |

Both Node dashboards default to port 3000, so run them one at a time or set `PORT`.

### Generated reports

Plotly artifacts written by evaluation runs of the reinforcement-learning
portfolio agents. Self-contained, but roughly 5 MB each — expect a slow first paint.
They are regenerated by the training pipeline, so treat them as output, not source.

| Page | What it covers |
|---|---|
| [Drawdown Evaluation](portfolio-optimization-engine/visualizations/drawdown_eval.html) | Drawdown curve across the evaluation period |
| [Portfolio Weights Evaluation](portfolio-optimization-engine/visualizations/portfolio_weights_eval.html) | Per-asset allocation weights as they evolve |
| [Risk Metrics Evaluation](portfolio-optimization-engine/visualizations/risk_metrics_eval.html) | Volatility, Sharpe and related risk statistics |

## Notes

- `trading-system-dashboard` serves its project root as static files, so once its
  server is running the four research pages are also reachable under `/templates/`.
- Page filenames under `templates/` were renamed to kebab-case (`Macro Overview.html`
  → `macro-overview.html`); spaces in filenames become `%20` in URLs and break
  shell tooling.
