About this data. Holdings are compiled from institutional 13F filings, tracked per investor/fund in a Notion database ("Big Giant Portfolio" → Investor Portfolio Holdings) and rendered here as a static snapshot. This page reads a single data.json file — to reflect changes from the source, regenerate data.json from Notion and redeploy (e.g. through the same Notion → GitHub → Vercel pipeline used for your other trackers) on whatever cadence the source refreshes (13F filings update quarterly; if the Notion database is edited more often, redeploy after each edit). No page code needs to change, only the data file.

Percent-of-portfolio, share counts, and reported prices reflect the last filing captured in the source database. "Change %" reflects the filing-over-filing change reported in that source.
