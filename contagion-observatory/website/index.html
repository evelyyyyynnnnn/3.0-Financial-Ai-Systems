The market here is synthetic, generated by src/market.py with a KNOWN set of transmitting edges. That is the point: correlation is everywhere in real market data and almost none of it is transmission, so a contagion method has to be tested where the true links are known. No real asset universe has been analysed.

Correlation is not transmission

A common factor makes every asset move together with no causal link at all, and in a crypto-equity panel that factor is large. So a correlation-based edge set is mostly false edges, and the whole problem is separating the two.

Two things do it. Removing the first principal component strips the shared factor, leaving residual co-movement where a real link shows up. And using a lagged correlation makes the measure directional, which a contemporaneous correlation can never be.

On raw returns, unlinked pairs show a tail lift of 7.97 — higher than most of the genuinely linked pairs. Everything crashes together because everything loads on the same factor, so tail dependence measured on raw prices carries no information about transmission whatsoever.

On factor-removed residuals, unlinked pairs fall to 1.29 while real links survive at up to 5.73. This is the single most important number on the page: a tail-dependence figure quoted without the factor removed is not evidence of contagion.

Multiplying by tail lift was the original design, and it is worse

Scoring each pair as |lagged correlation| × tail lift seemed obviously right: combine a directional signal with a stress-specific one. It ranks the true edges at a median position of 118 out of 306. Lagged correlation alone ranks them at 33.

The reason is visible in the table above: on residuals, several genuine links have tail lift below 1, so the multiplier suppresses exactly the edges it was added to surface. The whole grid is published rather than only the winning row, because reporting the configuration that worked without the ones tried first presents a searched result as a derived one.

At the best threshold the method finds 7 of 7 real links and surfaces 37 false candidates alongside them. That is a screening tool, not a detector: it takes 306 ordered pairs down to roughly 44 worth a human look, and does not miss a real link in doing so. Precision of 0.16 is the honest cost, and quoting the recall without it would misdescribe what the method does.

Two choices worth stating

Shocks propagate through the constructed edge set, not the estimated one. Pushing a shock through estimated edges compounds estimation error into a confident-looking fan-out that is mostly artefact, and it conflates two separate questions: can the network be recovered, and given a network, what does a shock do.

Only newly-received impact re-transmits. An earlier version carried each node's accumulated total forward every round, so nodes re-emitted their whole balance and a 20% shock produced 104% of total absolute impact — five times the energy that entered the system. It now decays, as it must.

Reproduce it

cd contagion-observatory
pip install -r requirements.txt
python -m pytest tests/ -q
python -m src.demo

For real data, replace src/market.py with a loader returning a returns matrix and asset classes. Everything in src/contagion.py is unchanged — but note that a real panel has no ground-truth edge set, so the recovery scores on this page have no real-data equivalent.

What this does not establish

  • No real assets have been analysed. There is no 7,500-crypto or 6,000-equity universe behind any figure here.
  • The generator was written by the same person as the method, and it embeds the linear lagged structure the method looks for. Real transmission is not linear and not one-day-lagged.
  • Recovery scores exist only because the edges were constructed. On real data there is no ground truth, so the method can be validated only indirectly — against known episodes, or out of sample.
  • Precision at best threshold is 0.16. This is a screening tool that hands a human a shortlist, not something to act on unsupervised.
  • Propagation is a linear cascade with no capital constraints, no liquidation dynamics and no feedback. It shows reachability, not loss.
