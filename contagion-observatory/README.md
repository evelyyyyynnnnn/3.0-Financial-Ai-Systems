# Contagion Observatory

> Which crypto-equity links actually TRANSMIT stress, separated from the much larger set that merely move together — and what a shock to one asset does to the rest.

**Repository:** `3.0-Financial-Ai-Systems` &middot; **Pillar:** Financial Stability

## Status

This is working code with a runnable demo and 0 tests. It is **not** a
finished result.

The default demo market is synthetic, generated by src/market.py with a KNOWN set of transmitting edges. That is the point: correlation is everywhere in real market data and almost none of it is transmission, so a contagion method has to be tested where the true links are known — and only there can precision/recall and shock-recovery be scored.

`python -m src.demo --real` runs the same pipeline on real data: the daily value-weighted returns of the Fama-French 10-industry portfolios (Kenneth R. French Data Library — 10 series over ~756 recent trading days) and ranks cross-industry transmission candidate links (lagged-correlation edges plus stress-day tail lift). On real data the true transmission graph is unknown, so the run honestly does NOT report precision/recall or shock recovery (`recovery_reported:false`), and the shock-propagation section is zero by design. See `results/latest-real.json`.

Last run: `2026-08-31T18:47:16+00:00`

## Quick start

```bash
pip install -r requirements.txt
python -m pytest tests/ -q     # 0 tests
python -m src.demo             # synthetic demo: known edges, scores precision/recall
python -m src.demo --real      # real run: Fama-French 10-industry daily portfolios
```

## The website

`website/` has no build step. To deploy it independently:

```bash
cp -r website/ ../my-contagion-observatory-site && cd ../my-contagion-observatory-site
git init && git add -A && git commit -m "site"
vercel deploy --prod
```

The page is regenerated from `results.json` on every `python -m src.demo`, so the
figures on the site and the figures the code produces cannot drift apart. Do not edit
numbers on the page by hand.

## Honesty note

The precision/recall and shock-recovery figures come only from the synthetic
demo, where the true transmitting edges are known &mdash; they are properties of
that constructed panel, not of any real market. The `--real` path runs the same
pipeline on real Fama-French 10-industry daily returns, but because the true
transmission graph there is unknown it reports only ranked candidate links, not
accuracy: no precision/recall, no recovery, and a shock-propagation section that
is zero by design. Nothing here measures the résumé-scale universe (7,500+
crypto / 6,000+ equities); the site's closing section states explicitly what the
project does not establish.
