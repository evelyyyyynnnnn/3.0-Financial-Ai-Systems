Giant Portfolio Tracker

机构持仓（13F）追踪器 — Institutional 13F holdings, refreshed from Notion on a monthly schedule.

做什么

A live, deployed site tracking 13F holdings across major investors and institutions — searchable by fund, manager, and fund type. Data is pulled from two Notion databases by a scheduled GitHub Action and committed back as data.json, which triggers a Vercel redeploy.

Static HTMLNotion APIGitHub ActionsPythonVercel

Fixed: the scheduled refresh had never run. workflow 此前位于 1-Giant-Portfolio/.github/workflows/。GitHub Actions 只读取仓库根目录的 .github/workflows/，因此该定时任务从未执行过。现已移至根目录，并将频率从每周改为每月 1 日。

核心模块

路径相对于 project-1/giant-portfolio/。

模块职责
giant-portfolio/index.html站点本身，数据变更时无需修改
giant-portfolio/data.json持仓数据，由刷新脚本重写
scripts/refresh_data.py拉取 Notion 两个数据库并重写 data.json
.github/workflows/refresh-data.yml每月 1 日 09:00 UTC 定时任务

如何运行

入口文件：giant-portfolio/index.html

export NOTION_TOKEN=ntn_xxxxxxxxxxxx
pip install requests
python scripts/refresh_data.py    # 重写 giant-portfolio/data.json

页面、报告、论文与 notebook。
