Portfolio Optimization Engine

强化学习组合优化与动态对冲 — Reinforcement learning for portfolio optimization and dynamic hedging.

做什么

Combines deep reinforcement learning with portfolio theory to learn an adaptive allocation policy. Three agents share one custom environment: a TensorFlow PPO implementation written from scratch, plus Stable-Baselines3 SAC (continuous weights) and DQN (discretised allocation grid).

PythonTensorFlowStable-Baselines3GymnasiumPlotlyTensorBoard

核心模块

路径相对于 project-1/portfolio-optimization-engine/。

模块职责
src/environments/portfolio_env.py组合管理环境，含技术指标与风险调整奖励
src/agents/ppo_agent.py自研 TensorFlow PPO 智能体
src/agents/sb3_agent.pyStable-Baselines3 SAC / DQN 封装
src/visualization/visualizer.pyPlotly 评估报告生成器
src/config/*.yaml三套智能体配置：default / sb3_sac / sb3_dqn

如何运行

入口文件：src/main.py

cd project-1/portfolio-optimization-engine
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python src/main.py --mode train --config src/config/sb3_sac.yaml

可查看的产出

页面、报告、论文与 notebook。

  • Drawdown Evaluation可直接打开评估期回撤曲线
  • Portfolio Weights Evaluation可直接打开各资产权重随时间演化
  • Risk Metrics Evaluation可直接打开波动率、Sharpe 等风险统计
